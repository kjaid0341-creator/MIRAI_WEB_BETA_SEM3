// 01 — capabilities

      
What ships with this.


      


        
        

          01 / primitive
          

          Zero-dependency CSS
          
            Every visual is produced by pure CSS custom
            properties and transforms. No framework.
            No runtime cost. Ships as a single file.
          
        


        
        

          02 / geometry
          

          Live WebGL scene
          
            Three.js renders a wireframe icosahedron with
            a starfield and smooth mouse parallax. Fully
            respects prefers-reduced-motion.
          
        


        
        

          03 / interaction
          

          Real 3D card tilt
          
            Each card reads cursor position and applies
            rotateX/Y transforms. Inner layers sit at
            different translateZ depths — genuine parallax.
