🚀 Running a React/Vite Project
1. Open the folder that contains that project's package.json.
2. Open a terminal in that folder.
3. Install dependencies if needed:
   npm install
4. Start the development server:
   npm run dev
5. Open the local URL printed in the terminal, usually something like
   http://localhost:5173.
Important: Run these commands inside the specific project folder,
not in the repository's parent folder unless its package.json is
there.
